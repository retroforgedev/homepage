Our Application

Screen Machine Translator

A convenient Android application for recognizing and translating text displayed on your screen.

ANDROID APPLICATION

ScreenMtl

Screen Machine Translator helps users translate text displayed on their Android device without manually copying the text into another application.

It is designed for use with applications such as games, chats, videos, documents, and other content where text may appear on the screen.

✓
On-screen translation Translate text displayed on your Android screen.
✓
Text recognition Recognize text from supported screen content.
✓
Convenient controls Access translation functionality while using other applications.
✓
Privacy focused Screen content is intended to be processed locally for translation functionality.
Privacy

Your privacy matters.

Screen Machine Translator is designed to minimize unnecessary collection of user information.

Screen Content

Screen content accessed for translation is intended to be processed on the user's device and is not intentionally uploaded to Retro Forge servers.

Third-Party Services

The application may use services such as Google ML Kit and Google AdMob. These services may process information according to their respective policies.

User Control

Android permissions are controlled by the user and can be reviewed or revoked through Android settings.
